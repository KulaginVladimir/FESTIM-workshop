# Введение в FESTIM v2.x

Материалы для введения в моделирование переноса изотопов водорода в материалах с помощью FESTIM.

## Установка (требуется conda)

```bash
git clone https://github.com/KulaginVladimir/FESTIM-Introduction.git
cd FESTIM-Introduction

conda env create -f environment.yml
conda activate festim-introduction
```

Примеры находятся в:

- `notebooks/fundamentals/` — основные элементы FESTIM;
- `notebooks/applications/` — практические задачи.
